Instructions de revue HERMES Sport

Activité entièrement fictive · 6 septembre 2026

Connexion et appairage

Application Android fr.hermes.sport.mobile, version 0.1.0 (code 2). La connexion est obligatoire. Au premier lancement, saisissez l'adresse HTTPS fournie dans le champ privé « User name » d'AppGallery Connect, puis un code d'appairage fourni dans les remarques privées « For reviewer ».

Il n'y a pas de compte ni de mot de passe classique. Chaque code est à usage unique pour un appareil : utilisez un autre code pour un second appareil. La date d'expiration figure dans les remarques privées. Si les codes sont utilisés ou expirés, contactez matthieu_felix@yahoo.fr.

Parcours de test

  1. Après appairage, consultez les trois séances de démonstration.
  2. Ouvrez le détail d'une séance pour consulter les mesures disponibles.
  3. Testez l'import du fichier TCX fictif ci-dessous et vérifiez son aperçu avant de confirmer.

La synchronisation Garmin et le Coach ne sont pas disponibles sur cette instance de revue.

Fichier TCX de démonstration

Ce fichier permet d'essayer l'import TCX dans HERMES Sport. Il ne contient aucune activité personnelle.

Télécharger le fichier TCX fictif

Dans l'application, ouvrez Sources, lisez les informations de confidentialité, cochez l'accord pour l'envoi du fichier, puis choisissez ce TCX. Vérifiez l'aperçu avant de confirmer l'import.
