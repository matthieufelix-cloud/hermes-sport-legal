APPGALLERY REVIEW

HERMES Sport reviewer instructions

Android 0.1.0 (version code 3) · fr.hermes.sport.mobile · Updated 22 October 2026

1. Connect using a pairing code

This app does not use a username and password login. It connects to a private HERMES server using a one-use pairing code. No account registration, Huawei Health login, VPN or Tailscale account is required. The application interface is in French.

  1. Open the installed app. In Adresse du serveur HTTPS, paste the complete HTTPS address provided in the private User name field of AppGallery Connect, including its port number.
  2. In Code d'appairage, paste one complete code starting with hmp. from the private For reviewer → Remarks field. Copy the whole code without spaces or line breaks. Do not paste the explanatory text from the AppGallery Password field.
  3. Tap Appairer ce téléphone (Pair this phone). The home screen loads the synthetic review activities.

Use a different code for each device. A code cannot be reused after successful pairing, including after signing out or reinstalling the app. Two separate reviewer codes are provided in the private remarks. They expire on 10 November 2026 at 22:59:59 UTC. If no unused code remains, contact matthieu_felix@yahoo.fr for another code.

2. Review activities and TCX import

  1. Open Séances (Activities), then open a synthetic activity to inspect its statistics and heart-rate chart. Some demonstration activities intentionally have missing measurements.
  2. Download the fictional TCX sample on the review device.
  3. Open Sources, read the privacy information, tick the consent checkbox and choose the TCX file. Inspect the preview, make sure the consent checkbox is still selected (tick it again if necessary), then tap Confirmer l'import. Return to Séances to inspect the result. Reimporting the same file may report that the activity is already present.

3. Review the AI Coach

Open Coach, enter Que signifie ma cadence de course pour mon entraînement ? and submit the question. Wait for the generated response. The response displays Réponse générée par intelligence artificielle (IA) and scientific references with their attribution and licence. The review instance uses synthetic activities and a separate scientific review corpus. Garmin synchronisation is unavailable on this instance.

4. Sign out last

When testing is complete, open Réglages → Déconnecter ce téléphone (Settings → Disconnect this phone). This revokes that device's session and returns to the pairing screen. Signing in again requires another unused pairing code.

Connection troubleshooting

If pairing fails, check that the server address includes https:// and the supplied port, and that only one complete hmp. code was pasted. If the code was already used on another device, try the other code. Please send the on-screen error and the device model to matthieu_felix@yahoo.fr if access still fails.

Aide en français

Dans l'application, recopiez l'adresse complète du champ privé « User name » dans « Adresse du serveur HTTPS », puis un seul code complet des remarques privées dans « Code d'appairage ». Touchez « Appairer ce téléphone ». Il n'existe pas de mot de passe classique. Chaque code est à usage unique ; un nouvel appareil ou une reconnexion après déconnexion nécessite un autre code.

Le profil de revue permet la consultation de séances fictives, l'import TCX avec consentement préalable et le Coach IA. Le fichier téléchargeable ci-dessus est entièrement fictif. Il ne contient aucune activité personnelle.
